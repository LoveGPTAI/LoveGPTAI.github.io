啟程：AI LLM Vibe Coding 與我的 EDA 筆記

2025-09-09 | 1 min read
#AI #EDA #Vibe Coding #Personal

建立這個部落格，是我想留下自己在 EDA 產業、AI 大語言模型（LLM）、以及個人 vibe-coding 之路的軌跡。
我希望它不只是一個技術筆記本，更能成為一個結合觀點、實驗與思考的空間。

為什麼開始寫？

✓ AI 正在改變一切
◻︎ 從程式設計、知識檢索，到數位分身與自動化，AI 已經成為日常工作流的一部分。
◻︎ 對我而言，AI 並非只是工具，而是 與我並肩的共創夥伴。

✓ EDA 產業的轉折點
◻︎ 從 Cadence 收購 Hexagon D&E，到 TSMC 的先進封裝與測試挑戰，產業正快速重組。
◻︎ 我希望用這裡，紀錄並分析這些事件背後的脈絡。

✓ Vibe-coding 的實驗精神
◻︎ 我喜歡在 VS Code 裡，用 Copilot、MCP Server 與各種 workflow 做嘗試。
◻︎ 對我來說，程式設計不只是生產力，更是一種氛圍、一種生活方式。

我想分享什麼？

➊ 產業觀察
✓ 半導體、EDA、AI 工廠、數位雙生
◻︎ 透過公開資訊與個人解讀，分析技術與商業模式的變化。

➋ 工具實驗
✓ LLM、MCP、VS Code、Hugo 自動化
◻︎ 分享如何讓 AI 融入日常開發，並提升生產力。

➌ 生活與思考
✓ 投資、學習、親子與個人成長
◻︎ 因為技術只是生活的一部分，背後還有更大的脈絡。

為什麼是 Hugo？

我選擇 Hugo + GitHub Pages 來搭建部落格，因為：

✓ 快速、輕量：不需要龐大後端，就能生成完整靜態網站。
✓ 自由度高：可以完全掌控版面與排版。
✓ 可持續：適合作為長期經營的知識倉庫。

未來展望

這裡將會是我探索 AI x EDA x 個人成長 的空間。
不追求「完美文章」，而是 持續更新、真實呈現。

如果這些內容也能給你啟發，或與你產生共鳴，那這個部落格就達成了它的意義。
